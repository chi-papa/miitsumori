# 📋 Mitsumori — 見積書・請求書メーカー

> インストール不要。ブラウザで開くだけで使える、日本語対応の見積書・請求書ジェネレーター。

---

## ✨ 特徴

- **ファイル1つで完結** — `mitsumori.html` をブラウザで開くだけ。サーバー不要・インストール不要
- **見積書・請求書を切り替え** — 書類の種類を選ぶだけでレイアウト・ラベルが自動切替
- **発行番号の自動採番** — `EST-2026-001` / `INV-2026-001` 形式で自動連番。年をまたぐと自動リセット
- **インボイス制度対応** — インボイス登録番号を記載可能
- **消費税の税抜・税込切替** — 入力モードをワンクリックで切替、金額を自動計算
- **PDF出力** — ブラウザの印刷機能でそのままPDF保存
- **書類の保存・呼び出し** — `localStorage` にリストを保存。複数書類を管理して何度でも呼び出せる
- **発行者情報の記憶** — 自社情報・銀行口座は一度入力すれば次回から自動入力
- **完全ローカル動作** — データはすべてブラウザ内に保存。外部サーバーへの送信なし

---

## 🚀 使い方

```
mitsumori.html をダウンロードして、ブラウザで開く。以上。
```

1. 書類の種類（見積書 / 請求書）を選択
2. 発行者情報・宛先・品目を入力
3. **「プレビューを見る」** でレイアウトを確認
4. **「PDF作成・印刷」** でPDF保存 または 印刷
5. **「書類を保存」** でブラウザにデータを保存 → 後から呼び出して編集

## 🔧 主な機能詳細

### 見積書モード
- 見積番号（自動採番）・発行日・有効期限
- 納期（ご注文より〇日前後）
- ご購入方法（楽天・Yahoo!ショッピング・その他）
- お支払い方法

### 請求書モード
- 請求書番号（自動採番）・発行日・お支払い期限
- 振込先口座（銀行名・支店・口座種別・口座番号・口座名義）
- インボイス登録番号

### 共通
- 品目の追加・削除・数量・単価を自由に編集
- 消費税 10%（税抜入力 / 税込入力を切替）
- 備考欄（注意事項テンプレートあり）
- 保存リストパネル：番号・宛先名・書類種別を自動で保存名に反映

## 💾 データの保存先

すべてのデータはブラウザの `localStorage` に保存されます。

| キー | 内容 |
|---|---|
| `doc_saved_list` | 書類リスト（JSON配列） |
| `doc_from_info` | 発行者情報 |
| `doc_bank_info` | 振込先口座情報 |
| `doc_invoice_no` | インボイス登録番号 |
| `doc_tax_mode` | 税モード（税抜 / 税込） |
| `doc_type` | 書類種別（見積書 / 請求書） |
| `doc_counter_est` | 見積書の連番カウンター |
| `doc_counter_inv` | 請求書の連番カウンター |

> ⚠️ ブラウザのデータを消去するとすべてのデータが削除されます。定期的にPDFへの出力を推奨します。
